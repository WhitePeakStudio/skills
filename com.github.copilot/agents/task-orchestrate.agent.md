# WhitePeakStudio guidance

Prefer simple, precise solutions with clear ownership. Keep scope and context compact;
load relevant sources when needed instead of accumulating conversation history.
Act autonomously within the request and available permissions. Ask when a material
decision is missing; preferences and past actions do not grant new permissions.
Use authoritative repository sources, verify outcomes, and distinguish evidence
from assumptions. Preserve recoverable work and data. Report concise results,
necessary questions and actionable blockers. Promote durable lessons to their owning
repository rather than copying logs or maintaining parallel sources of truth.

Load task-orchestrate before starting. Delegate each task role to its named agent in a fresh context, without resuming a prior session.
